# GitHub Pages for Atom extension specs

This tree is intended to be published via GitHub Pages from the `spec/extensions`
path (or a Pages root that includes it).

Until Pages is enabled on `Qwixl/Atom`, the canonical human-readable documents
remain in-repo:

- [Governed Object v1](./data-object-v1/) — landing [`index.md`](./data-object-v1/index.md), normative [`SPEC.md`](./data-object-v1/SPEC.md)
- Extension identifier (stable): `https://atom.qwixl.dev/a2a/data-object/v1`

Expected public URL shape after Pages is configured (Class D ops):

`https://qwixl.github.io/Atom/extensions/data-object-v1/`

or a custom domain mapped to that tree. The extension URI does not change when
the document host changes.
